# 岩迹 · 品牌标志规范

> v0.3.10 · 2026-11-16 · 标志名「一条线路」

## 1. 定位

岩迹是**一个人的攀岩手账**：不记录成绩、不做社区、不做训练计划，只把每一次攀爬留下来。

主线是「记」：一次攀爬 → 一条线 → 攒成山、阶、迹。所以标志不画山，也不画成绩曲线，而是画**一条被手绘下来的攀岩线路**。

## 2. 概念

一条柔和的 S 形线路，从山脚/墙脚爬到顶：

- **线**：一条软曲线（不是折线，也不是图表），像在岩馆墙上用粉笔/手指画下的 route；
- **起点**：左下是线的起点（墨色的圆头），代表第一次记录；
- **两个白点**：线上的两个小圆是**镂空的岩点/螺栓孔**（不是白色填充），让线看起来是“挂在墙上的一条线路”；
- **到顶**：顶端一颗橙点，是整条线唯一的高光颜色，代表到顶。

## 3. 构成与几何

母版 `brand/yanji-symbol.svg`（256 × 256）：

| 元素 | 参数 |
|---|---|
| 中心线 | `M56 208 → 82 176 → 120 170 → 144 140 → 156 100 → 186 52` 的平滑曲线 |
| 线宽 | 13（圆头，无描边，直接是填充形状） |
| 岩点孔 | 两个圆，r = 5.4，圆心 (116,170) / (150,124)；用 mask 真正镂空，外圈再描 3.4 的墨线 |
| 到顶点 | 圆心 (186,52)，r = 11，橙 `#E2552B` |
| 留白 | 四周约 40–60，至少留一根线宽 |

**小尺寸切版** `brand/yanji-symbol-small.svg`：去掉两个镂空孔，线宽加到 22，橙点 r = 14；用于 16–24 px（favicon 用的就是它）。

**单色 / 深色**：`variants/` 下有黑、白、单色墨、方形；深色底用 `yanji-symbol-dark.svg`（纸色线 + 橙点，孔仍镂空）。

## 4. 标准组合

| 组合 | 文件 | 用途 |
|---|---|---|
| 横版 | `brand/yanji-lockup-horizontal.svg` / `.png`（透明底） | 首页、页头、分享图角标 |
| 竖版 | `brand/yanji-lockup-stacked.svg` / `.png` | 启动页、空状态、周边 |
| 深色横版 | `brand/yanji-lockup-horizontal-dark.svg` / `.png` | 深色底 |
| 单色横版 | `brand/yanji-lockup-horizontal-mono.svg` | 单色印刷 |

字标：**岩迹** 用霞鹜文楷（与 app 一致）；英文 `YANJI` 字距加大的一行小字。当前 lockup SVG 里的中文是**活字**，正式对外印刷前需要转曲；网页里用 HTML 文字 + 标志即可。

## 5. 用色

| 名称 | HEX | 用途 |
|---|---|---|
| 墨 | `#1F1D19` | 线路、文字、岩点孔外圈 |
| 纸 | `#F4F0E6` | 背景（镂空处透出底色） |
| 橙 | `#E2552B` | 只给到顶点 |

标志只允许 1–2 色：墨 + 橙；单色时全部转墨。

## 6. 使用规则

- **留白**：标志四周至少留一根线宽（≈ 标志高度的 1/10）。
- **最小尺寸**：主标 ≥ 32 px；16–24 px 用 `yanji-symbol-small.svg`；横版组合 ≥ 160 px 宽。
- **背景**：优先纸色 / 纯色底；不要压在插画、照片或纹理上（需要时先垫一块纸色底）。
- **不要**：改曲线走向、把橙点放到线中间、把岩点孔做成实心白点、加投影/渐变/描边。
- **动效**（以后）：可以让线自己“画”出来，橙点最后落下；不要弹跳。

## 8. 生成方式

线路是**一条描边路径**（stroke 13，圆头），两个岩点孔用 `<mask>` 镂空；母版用少量锚点，方便以后烘成填充路径或做刺绣/切割。PNG 由 SVG 渲染，没有位图底。改颜色时只改 `stroke` / `fill`，不要改曲线和孔位。
