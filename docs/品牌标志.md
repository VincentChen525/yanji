# 岩迹 · 品牌标志规范

> v0.3.9 · 2026-11-16 · 标志名「刻痕」

## 1. 定位

岩迹是**一个人的攀岩手账**：不记录成绩、不做社区、不做训练计划，只把每一次攀爬留下来。

产品的主线是「**记**」：一次攀爬 → 一条线 → 攒成山、阶、迹。所以标志不去解释“攀岩”（山、岩点、快挂、攀岩鞋这些符号太容易被读成某项功能），而是解释「**记录与痕迹**」。

## 2. 概念：刻痕

四道竖刻痕 + 一道橙色斜杠：

- 每一道竖刻痕 = 一次攀爬；
- 橙色斜杠 = 今天这一下（“正字”记账的最后那笔）；
- 刻痕是全世界最早的记账方式，和“记一条线”是同一个动作；
- 它也能直接当 UI 里的计数符号：分享卡角落盖一组，就是“这个月爬了 23 次”。

## 3. 构成与几何

母版 `brand/yanji-symbol.svg`（256 × 256）：

| 元素 | 参数 |
|---|---|
| 竖刻痕 | 4 条，宽 24，圆头，长度 146–156（手作感），x = 64 / 104 / 144 / 184 |
| 斜杠 | 宽 24，圆头，从 (44,172) 到 (212,92)，旋转 −25.46° |
| 颜色 | 竖刻痕墨 `#1F1D19`；斜杠橙 `#E2552B` |
| 外框 | 透明底；四周留白约 44（≈ 一根刻痕的宽度） |

**小尺寸版** `yanji-symbol-small.svg`：4 竖减为 3 竖（x = 74 / 126 / 178），线宽 30，斜杠 −30°；用于 16–24 px（favicon 用的就是它）。

**单色 / 深色**：`variants/yanji-symbol-black.svg`、`yanji-symbol-white.svg`、`yanji-symbol-dark.svg`（纸色刻痕 + 橙斜杠，用于深底）。

## 4. 标准组合

| 组合 | 文件 | 用途 |
|---|---|---|
| 横版 | `brand/yanji-lockup-horizontal.svg` / `.png`（透明底） | 首页、页头、分享图角标 |
| 竖版 | `brand/yanji-lockup-stacked.svg` / `.png` | 启动页、空状态、周边 |
| 深色横版 | `brand/yanji-lockup-horizontal-dark.svg` / `.png` | 深色底 |
| 单色横版 | `brand/yanji-lockup-horizontal-mono.svg` | 单色印刷 |

字标：**岩迹** 用霞鹜文楷（与 app 一致）；英文 `YANJI` 字距加大的一行小字。当前 lockup SVG 里的中文是**活字**，正式对外印刷前需要转曲；网页里用 HTML 文字 + 标志即可。

## 5. 用色

| 名称 | HEX | 用途 |
|---|---|---|
| 墨 | `#1F1D19` | 刻痕、文字 |
| 纸 | `#F4F0E6` | 背景 |
| 橙 | `#E2552B` | 只给斜杠这一笔 |

标志只允许 1–2 色：墨 + 橙；单色时全部转墨，不能出现第三种颜色。

## 6. 使用规则

- **留白**：标志四周至少留一根刻痕的宽度（≈ 标志高度的 1/8）。
- **最小尺寸**：主标志 ≥ 32 px；16–24 px 用 `yanji-symbol-small.svg`；横版组合 ≥ 160 px 宽。
- **背景**：优先纸色 / 纯色底；不要压在插画、照片或纹理上（需要时先垫一块纸色底）。
- **不要**：拉伸压扁、改斜杠角度、把橙色用到竖刻痕上、加投影/渐变/描边、把刻痕排成 5 道以上（会变成正字）。
- **动效**（以后）：可以逐道“画”出刻痕，斜杠最后落下；不要弹跳。

## 8. 生成方式

标志全部是**实心几何**（无描边）：竖刻痕是胶囊矩形，斜杠是旋转的胶囊；PNG 由 SVG 渲染，没有位图底。改色时只改 `fill`，不要改角度和比例。小尺寸切版必须单独维护，不要直接缩主标。
