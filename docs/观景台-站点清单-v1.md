## 一、规则复核

- 只给 14 座山，15 座建筑不给站。
- 每座 1–6 站，珠峰（10 站）和乔戈里峰（8 站）例外——真实路线的节点本来就多。
- 首站尽量 ≤ 目标的 35%，受真实地理限制可以放宽到 50%（半穹顶 46%、玉龙 43%、酋长岩 53%）。
- 相邻两站间距尽量 ≤ 30%；超过 40% 的标 ⚠，说明这一段反馈偏稀。
- 优先真实地名；低段没有真实地点时，用真实的出发地 / 山门补，不编地名。

**当前 14 座 / 61 站**。确认记录见第三节。
