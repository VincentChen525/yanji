# 岩迹

把每一次室内攀岩，记成一条线。

**线上体验**：https://vincentchen525.github.io/yanji/

> 室内攀岩记录应用的单文件原型（v0.3）。不做视频 / 图片 beta，也不做社交社区——只做自己的账本：记录每一次攀爬，再把记录变成一座山、一级阶、一段迹。

## 能看到什么

- **今天**：一面岩壁，记下每条线的结果、掉点位置和方式；同一条线换方式爬会分开记。
- **山**：累计爬升一座座「爬」过 29 个真实地标（建筑 15 座 + 山 14 座），路上有 61 个基于真实地点的观景台；到站给一段「这段路」的小结。
- **阶**：先锋 / 上方保护 / 抱石分开报级别，1 条解锁、3 条站稳、5 条吃透，附「方式落差」——同一条线顶绳能上、先锋没上去这类对比。
- **迹**：一年点阵、周期总结、「看出来的」结论卡，最后把统计整理成一段话交给任意 AI 复盘。
- **线路簿**：岩馆换线后，一条线可以在线路簿里「拆线」——电动螺丝刀拧下岩点螺丝的小动画；拆掉的线都留着，随时「装回去」。

## 跑起来

```bash
cd 攀岩
python3 -m http.server 8765 --bind 127.0.0.1
# 打开 http://127.0.0.1:8765/
```

也可以直接双击 `index.html`（本地文件模式下字体可能回退到系统楷体）。

## 说明

- 单文件原型：`shengji-prototype.html`，无构建、无依赖、vanilla JS + SVG。
- 记录只存在浏览器的 localStorage，不上传；可备份成文件或一段文字。
- 首次打开看到的是示例数据（一个爬了半年的用户），在「今天」页底部可以清空，开始记自己的。
- 抱石每次按 4 米折算成爬升；难度用 YDS / V 级。
